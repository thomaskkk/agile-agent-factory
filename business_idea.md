I want a simple web app to keep track of recipes I like.

The idea is pretty straightforward — I find recipes online or come up with my own, and I want somewhere to save them so I can look them up later. Each recipe should have a name, the ingredients, and the steps to make it. It would also be nice to tag recipes with things like "vegetarian", "quick", or "dessert" so I can filter by those later.

The home page should show all my saved recipes in a simple list or grid. I should be able to click on one to see the full details. There should also be a simple form where I can add a new recipe — just fill in the fields and submit.

I don't need user accounts or anything like that. One person using it is fine. The data can live in memory for now, no database needed, but the app needs to actually run in a browser — so a real web server with real pages, not just a Python script.

It should be easy to test the backend logic with automated tests.
